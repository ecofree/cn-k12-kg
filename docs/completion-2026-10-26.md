## 内容改进

新完整卡覆盖小学原缺失的图形、分类、估算、观察与问题解决内容，初中剩余五册及七上的目标补全，以及高中必修和选择性必修全部核心点。
每张卡包含概念、为什么成立、使用信号、具体步骤、完整例题、条件边界与易错点。
其中推理类内容给出推导和反例，例如数学归纳法完整的基础与归纳步骤、向量基底表示的唯一性、驻点不一定是极值、三视图不保证任意立体唯一、统计相关不证明因果。

18项实践活动均有任务情境、材料、步骤、学生作品要求、参考过程及量规。新增15项分别覆盖时间记录、数学连环画、大数估测、路线图、体育统计，以及初中的跑道设计、白昼时长、薄板重心、最短路径、音乐比例、统计分析、列车模型、二次函数优化、停车布局和建筑几何。
几何项目明确模型、摆放与测量假设；示例数据明确是教学算例，没有伪造真实测量或学生成效。

旧50张速查卡也已逐张复查、修正并重建。修复内容包括：

- 20的十进制组成、从刻度1量长度的误差方向、306×2的正确结果、整百近似数的判断数位。
- 全等三角形拼成矩形或正方形所需的条件、圆柱滚动方向与物体可见面的对象限定。
- 最小正倍数、非零除数和倒数、正分数比较、a²与2a可能在0和2相等。
- 数对与实际距离所需的尺度、扇形面积比较所需的半径条件。
- 简单随机抽样与比例分层的区别、随机样本仍有抽样误差、频数与频率密度图的纵轴及面积意义。
- 卡方近似的条件、显著性水平与假设真假概率的区别、未拒绝独立不等于证明独立。

## 工程改进

### 可重建的题库与选项

所有内容从23册显式登记源和应用题生成器构建，历史补丁不参与隐式覆盖。
选择题在全部题源合并后统一排列：以题ID哈希确定顺序，按选项数轮流分配实际显示位置，正确答案继续绑定原稳定选项ID。

三选项175道的正确显示位置为59/58/58；四选项975道为244/244/244/243。
这个分布只避免显示位置偏置，不证明题意正确。构建前后已逐题检查正确选项内容保持不变；字母或“前三项”等位置依赖解析改为引用具体内容。
既有审核哈希没有自动重签，内容或选项顺序变化会使旧审核失效。

平衡CLI和应用题写入CLI均走统一构建路径。直接增删旧生成产物里的选择题而造成顺序歧义时，工具安全拒绝，并提示修改登记源再重建。
发布清单覆盖源文件、变换代码、教学材料、课标比较及前端文件。

### 学习界面与记录

网页展示逐项目标解释、自检输入框和默认折叠的参考过程；精确SVG帮助观察展开图、三视图、梯形高、统计图、函数分段与截线角关系。
开放自检提示其文本只保留在当前页面；正式练习和检查仍走服务端持久化会话。
既有练习即时反馈、整组检查后显示解析、过程题等待复核、历史恢复、版本绑定与导出均保持可用。

浏览器验收额外发现并修复启动时立即进入历史记录会被迟到的深链课程导航覆盖的问题；现在历史入口等初始化导航完成后启用。

### 完成门禁

新增 `tools/release_check.py`，一次运行来源一致性、图与题库结构、讲解、自检、单元、项目、课标、完成缺口、数值复算、回归及内容库构建。
`coverage_report.py --require-complete` 在真实制作缺口存在时返回失败；教师与学生两项暂缓事项保留独立状态。
回归测试实际删除临时副本中的完整卡，确认速查和单元关联无法掩盖完整卡及目标材料缺口。

## 使用

```bash
python tools/release_check.py
python web/server.py --port 8765
```

浏览器打开 `http://127.0.0.1:8765`。原项目采用Python标准库与本地前端资源，核心功能无需额外Web框架。
学习记录默认写入 `var/learning.sqlite`，内容库重建输出 `build/kg.sqlite`，两者分开。

教师独立审核与真实学生效果验证仍按用户要求暂缓，不影响本轮完整工程交付；内容保留真实的AI作者与draft状态。
