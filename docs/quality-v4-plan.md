# Quality V4：八项质量要求与实施范围

基线：`9f0471009f13590beee850ca5dd4999ff64d14fd`。分支：`codex/cnkg-quality-v4`。

用户授权继续三批实施，并以以下八项要求验收。教师独立审核与真实学生效果验证继续暂缓；保留其真实状态，不作为本轮实现的阻塞条件。课程范围沿用现有中国小学至高中数学 23 册及其登记资料，不通过删除困难目标或把基础概念改成扩展内容来缩小承诺。

## 固定验收要求

| 编号 | 要求 | 本轮可检查的产物与行为 |
| --- | --- | --- |
| Q1 | 范围明确 | 所有教材位置及登记目标都有明确角色、材料、任务与完成条件；核心、基础支持、扩展分别统计；旧复合目标不假装已原子化 |
| Q2 | 材料能教 | 承诺目标可找到具体解释、条件、参考过程、合适表征与可保存的学习活动；内容不足明确报错，不能仅按字段数判断 |
| Q3 | 题目能说明问题 | 任务明确说明直接观察范围与未覆盖范围；未知映射继续保留未知，不能按同主题自动补齐细目标；准入与文本启发式分开 |
| Q4 | 错误后有帮助 | 典型困难有可执行的辨别、分层提示、指导或量规修订；帮助内容和实际使用有版本与事件记录 |
| Q5 | 后续任务有依据 | 细目标、题族、表征、帮助记录与真实间隔参与推荐；看过解法后的作答不能冒充无帮助证据 |
| Q6 | 未解决事项不被忘记 | 已完成教材检查中的问题、较早过程题和partial/revisit自评跨会话、阶段、版本持续可见；关闭或暂缓具有明确依据 |
| Q7 | 学习资产能恢复 | 同环境恢复身份及新环境导入完整备份，保留快照、作品、修订和事件；错误备份不覆盖现有资料 |
| Q8 | 质量维护可持续 | 语义变更及影响清单、单元成品预览、内容检查与固定提交全量验收；收敛历史写入入口 |

“完成”必须对应上述产物和行为；不由题目总数、测试数量或一张总分表替代。题族独立性、真实难度和教学效果没有实证时不作推断。

## 第一批：学习问题、档案恢复与课程范围

修复已确认的教材检查后无持续计划、旧过程题被新阶段遮蔽、自评需要重做却不改变建议；建立可重建的学习问题与证据汇总。提供恢复凭据和完整备份／恢复。冻结各目标用途与完成要求，并明确当前题目准入，保留旧答案与历史身份。

## 第二批：教学帮助与课程内容

先贯通现有分数—比例—一次函数、读数据—抽样—回归两条链的辨别与分层帮助，再推广至已有单元与目标自查。核对逐目标阶段覆盖，补足实际缺口，修正减法关键词、估算条件、平均数分类等已确认问题；补高中综合实践和有数学作用的操作表征。

## 第三批：范围完善、维护和发布

按课程矩阵逐项补材料与任务缺口，呈现真正可执行的目标入口。提供语义差异与影响检查、受影响单元预览，整理历史工具与无调用代码。固定源码后运行核心、教学帮助、恢复和浏览器验收，实际恢复发行历史并校验交付文件。

## 兼容与工作边界

- 原任务与技能ID不重编号；修改数学含义应有明确版本，不批量重判历史作答。
- 原会话、作品、修订和事件保留；迁移只增加必要结构或重建派生索引。
- 现有可读导出和完整恢复备份是不同用途，界面与文件类型明确区分。
- 既有复习间隔保持可解释的产品规则；完成、自评与提示后正确不转换成独立掌握。
- 正式发布证据必须绑定同一干净提交。GitHub是否同步以实际远程引用为准。
