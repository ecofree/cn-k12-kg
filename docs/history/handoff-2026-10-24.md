1. **120 道选择题只有 3 个选项**（猜中率 33%，四选项是 25%）。

5. **三档判定上限约 71%**：实验证明加更难的题无效（`tools/ladder_experiment.py`），要提升只能加同一难度的独立题，或接受二档。

## 8. 交接包怎么用

打包文件：`build/to-astra.zip`（30 KB，7 个文件），源目录 `inbox/`。

```bash
python tools/export_inbox.py          # 重新生成模板（数据变了就跑）
# 对方填好后放回 inbox/，然后：
python tools/ingest.py --check        # 校验 id / 字段 / 覆盖率，不改任何数据
python tools/ingest.py --apply        # 课标补原文、复核结论入库
```

`--apply` 只做三件安全的事：课标加原文与出处、复核结论汇总到 `data/reviews.json`、外部映射复制到 `data/external/`。
**改题目难度、改先修边不会自动发生**——必须先抽检映射，否则等于把「看起来有条理」的数字当校准结果。

格式约定由 `tests/test_ingest.py`（14 个用例）守着：id 不存在、verdict 非法、正确率越界、新增叶子缺 source，都会在 `--check` 阶段报错，不会带病写库。
