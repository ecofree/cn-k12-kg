# Quality V5：学习判断、课程对齐与学习体验

基线：`3666ba3f00d4fb0f43ae0788a921689d9d505882`。本轮按三批先后实施；教师独立审核和真实学生教学效果验证继续暂缓。当前产品范围仍为中国小学至高中数学，不扩大为全学科平台。

## 第一批：先让判断可信、档案可找回

1. 未知表征不算新表征，未分类题族不算独立任务。
2. 计划按钮和复测判定共用真实活动时间、内容版本与间隔规则。
3. 有帮助的修订完成后，保留绑定原目标的独立确认事项；练习、暂缓和内容更新不能静默清除它。
4. 切换档案前保护当前非空档案的找回凭证；服务端检查，空浏览器直接恢复仍可用。
5. 修正棱台题的目标错配，拆出必要行为；重新核定直接抄读数字等任务的用途。

验收使用上一轮审计中的具体反例、真实端点与原记录恢复，不通过改变测试期望掩盖行为缺陷。

## 第二批：让目标、材料、题目与帮助真正对上

1. 支持按真实教学复杂度登记不同数量的目标，保留原复合目标和稳定身份，明确细化关系。
2. 为重点学习链逐项审查目标与任务映射、数学结构题族、实际表征、观察边界和困难支持。无依据的项继续显示未知，禁止用题号、关键词或任意标签伪造语义覆盖。
3. 补空间图形、分数、函数及统计等必要表征与目标支持；图示须服务具体推理，含方向、尺度、条件和反例。
4. 建立可重算对齐报告：分开显示基础材料结构、目标专属帮助、可观察任务、已知题族与表征、独立后续机会。结构齐备不再作为综合优质结论。

验收包括独立复算、错误答案与条件反例、映射的反向核对、真实页面；扩大覆盖时必须同时增加真实内容与审查证据。

## 第三批：把对齐结果变成可使用的学习流程

1. 典型困难采用小而明确的教学分支，诊断选择影响后续指导；保留每条路线的边界。
2. 计划页显示并打开具体目标、前置支持和所选任务，解释安排依据。
3. 增加低年级可点击操作、预测后检验、多表征联动，以及限定数学范围内的分步反馈；作品、帮助及修订可保存。
4. 备份显示新鲜度和容量，明确支持的版本与恢复路径；升级不能让用户误以为恢复已经完成。
5. 将错误反例和语义检查纳入持续维护，在新的固定提交上执行核心与浏览器验收并重新打包。
