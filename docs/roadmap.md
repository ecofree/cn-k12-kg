## 完整缺口继续公开

当前对齐报告要求的三项全目标条件已覆盖1,136项，但任务级完整性和后续观察机会仍有不同缺口。当前值来自最终构建后 `build/final-alignment.json` 对应的对齐报告，使用 `python tools/check_alignment.py --check` 可重新计算；题族等价关系改变后必须重新计数。

前三组任务可以重叠，不应相加为独立题数。多客观题族统计已合并已审查的等价名称；66项实践目标按作品量规单独观察，作图、口头说明、证明和探究也不为凑数字改成客观题。一个已登记题族表明作者提出了结构分类，未证明经过真实学生数据验证的独立迁移。

104项目标支持均有辨别与指导，不代表104项都拥有不同错误各自对应的实际任务；当前明确分支的是其中27项。后续扩展应针对真实错误假设写不同辨别、指导和修订，继续保留其余支持的当前边界。

## 用户已明确暂缓的两项

- 教师独立审核保持待审核；AI作者与AI交叉核对不能代签教师身份。
- 真实学生教学效果验证不虚构参与者、对照组、学习增益、长期保持率或难度校准。

两项未被计作完成，也不阻断已经授权的工程与材料维护。真实验证开始时另行确定范围、记录方式与判断依据。

## 持续维护顺序

内容修订按“目标及条件 → 任务与量规 → 解释与表征 → 作者JSON → 编译及差异检查 → 具体语义复核 → 实际页面预览 → 固定版本验收”的顺序进行。题面改变必须同时核对答案、旧 `accept`、唯一有效评分合同、题族与任务用途，单独通过 `verify` 不足以接纳变化。

不进位与进位、恢复原量与继续当前量等结构区别需有明确判断。等价改名通过审查后的别名登记参与比较；原任务、答案、选项身份、曝光与作品历史不批量重写。新版提示只归因实际展开的方法，不能用未展开的后续内容扩大曝光，也不能清零同族记录将旧方法包装成未见证据。

新诊断不为未作答先修生成 `assumed`；历史推断保留并标为未实测。计划必须检查实际观察了哪个目标，保留其他目标的先修入口。帮助后完成、学生自评和过程修订可以改变后续安排，不能直接变成独立掌握；缺少适合的后续任务时保留待观察事项。

新答案、图示、提示和量规产生新内容版本。先保存独立原作答再展示帮助，保存失败或冲突保留输入；旧作品继续使用旧快照，不能因现版资源同名就替换参考或重判旧答案。未解决事项跨会话、阶段、学段和内容版本保留。

教材、课标条款、授权来源及发布依赖继续维护。学校账号、云同步、多租户和公网部署属于可选扩展；完整无障碍符合性也需要另有范围的审核，不能由手机宽度和键盘定向检查替代。

新增或修改发行文件后重新生成发布清单并提交，在干净提交上运行全套门禁。失败、遗漏或旧指纹报告不用于打包；具体步骤见 [发布流程](release-workflow.md)。
