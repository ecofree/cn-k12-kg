## 用户已明确暂缓的两项

- 教师独立审核保留待审核状态，AI作者核对不能代签。
- 真实学生教学效果验证不虚构参与者、对照组、长期保持率或难度校准。

它们不阻断本轮工程和材料交付，也没有被计作已完成。

## 持续维护

内容修订按“目标及条件 → 任务与量规 → 解释及表征 → 作者JSON → 编译检查 → 实际界面预览 → 绑定版本发布”的顺序进行。新细目标必须有可观察表现；旧复合目标不能仅改标签就算完成拆分。

新增题族需核对数学结构及表征；仅换数字和表面情境保持同族。材料曝光与已做任务不能通过清零记录重新包装为未见证据。新答案、新图示或新量规应产生新内容版本，原学习记录继续使用原快照。

教材版本、课标条款、证据策略和授权来源持续维护。跨设备账号、学校服务及公网部署是可选产品扩展，不是当前本地版本的隐含承诺。完整无障碍符合性和全课程语义细审仍需有明确范围的后续工作，不能由当前手机布局检查替代。

下一次扩展应继续按真实缺口选择主题，优先有具体图示、解释与迁移任务的几何、代数和建模学习链。不要用统一套模板、每节点固定题量或仅登记ID来宣称达到整部K12课程的细技能覆盖。已有未映射细目标明确保留边界；统计新链的映射和数学反例见 [内容说明](quality-v3-content.md)。
