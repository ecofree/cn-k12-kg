## 用户已明确暂缓的两项

- 教师独立审核保持待审核；AI 作者与 AI 交叉核对不能代签教师身份。
- 真实学生教学效果验证不虚构参与者、对照组、学习增益、长期保持率或难度校准。

两项未被计作完成，也不阻断已经授权的工程与材料维护。真实验证开始时另行确定范围、记录方式与判断依据。

## 持续维护顺序

内容修订按“目标及条件 → 任务与量规 → 解释与表征 → 作者 JSON → 编译及差异检查 → 具体语义复核 → 实际页面预览 → 固定版本验收”的顺序进行。题面改变必须同时核对答案、旧 `accept`、唯一有效评分合同、题族与任务用途；单独通过 `verify` 或作者答案自判不足以接纳变化。

有限目标必须说明观察行为和条件。已给模型的计算不能冒充自主建模，输入数值不能冒充作图、口头表达或证明；相关支持关系也不自动构成 `refines` 或先修蕴含。原目标、位置和 ID 保留，新增解释、辨别、提示、分项与标准必须读实际任务逐项写出。`data/assessments/` 显式维护目标、分项和任务的双向绑定，私有计算参考不随公共导航提前展示；共享任务使用当前进入目标的分项，不能自动选第一个关联目标。[V8 分项说明](quality-v8-continuation.md#过程如何留下可查看的证据)

不进位与进位、恢复原量与继续当前量等结构区别需有明确判断。已声明族的等价改名使用 `data/task_family_aliases.json`；历史未知族使用 `data/task_family_history.json` 中经逐题审查的负向曝光关系。V8 的 `data/task_family_transitions.json` 只为已核对的确切题目及旧／新合同续接保守曝光，不给整个题族建立泛化别名。合同改变时须判定结构是否仍相同，不能仅凭同 ID 自动认同。原分类、答案、选项身份、曝光与作品历史不批量重写，也不能清零旧接触把改名后的方法包装成未见证据。

新版提示只归因实际展开的方法，不能用未选路线或后续内容扩大曝光。主族与辅助族都按实际提供时机记录。帮助后完成、学生自评和过程修订可以改变后续安排，不能直接变成独立掌握；缺少适合的后续任务时保留待观察事项。

新诊断不为未作答先修生成 `assumed`，历史推断保留并标为未实测。计划检查实际观察了哪个目标，保留其他目标的先修入口；没有错误记录的未完成指导也能继续。推荐优先覆盖不同候选题族，数量变式不能挤占其他方法。[运行审查](reviews/v7-runtime-continuation-review.json)

新答案、图示、提示和量规产生新内容版本。先保存独立原作答再展示帮助，保存失败或冲突保留输入；相同提交重试返回已保存结果，不重复计分或造事件。旧作品继续使用原快照，缺少字段如实说明；缺摘要不能调用当前引擎补判，缺当前任务的旧活动保持未完成阻塞。未解决事项跨会话、阶段、学段和版本保留。

真实图片和录音附在具体过程分项上，保存原字节及明确文件归属；新版删文件仍保留旧修订。文件头、大小与 SHA-256 校验保障存储边界和一致性，不评价数学表现。刷新、历史回看、导出、完整加密备份及全新环境恢复均需保留原文件、原 SVG 和冻结公开分项，当前作者修改不能覆盖旧会话。文件格式和限制见 [恢复与迁移](profile-recovery.md)。没有实际录音、图稿或操作记录时继续标未观察。

概率统计、方程反例和数值正文按专项记录维护；故意错误示例须绑定具体位置、完整语境和指纹，不能用关键词全局跳过。当前新增 14 处故意错误等式位置与原 13 处历史例外分别保留，只有实际题意与纠错理由经过审读的具体位置才可接纳。程序精确核算的范围与模型条件、一般证明、数学语义分别说明。[V8 数值反例审读](reviews/v8-numeric-counterexample-review.json) · [V7 统计任务历史审查](reviews/v7-statistics-task-mathematics-review.json)

教材、课标条款、授权来源及发布依赖继续维护。学校账号、云同步、多租户和公网部署属于可选扩展；完整无障碍符合性也需要另有范围的审核，不能由窄屏与键盘定向检查替代。

新增或修改发行文件后重新生成发布清单并提交，在同一干净提交上运行 21 项核心门禁与 18 条真实浏览器旅程，共 22 项顶层门禁。新增过程文件旅程须实际提交合成图片／音频、刷新恢复、检查窄屏并回看附件旧修订；全部受影响页面还须实际打开。失败、遗漏或旧指纹报告不用于打包，专项测试不替代最终集成报告，文档描述也不预先宣告 CI 通过。具体步骤见 [发布流程](release-workflow.md)，运行与资产交接见 [handoff](handoff.md)。
