# 题量储备规划

## 一、为什么要储备题量（不是题海战术）

诊断引擎一次要问同一个知识点最多 2 题，且要区分「真会」和「不稳」——
题库只有 2 道时，学生答对 2 道就被判「掌握」，**这个知识点从此不再被问**。

但更根本的问题是**记忆**。初高中有 25–32% 的知识点是「公式/定理/性质/判定」
这类需要自动化提取的内容（86 个记忆型点）。这类知识的掌握不是「理解了」，
而是**能在考场 30 秒内调出来**。

提取练习（retrieval practice）的效果依赖于：
- **提取次数**——只做 2 题，考场调不出来
- **提取的变式**——同一个问法记住了，换个问法还是不会

所以储备量要按「**同一知识点、不同问法**」来算，不是靠重复同一道题凑数。

## 二、储备目标

| 知识点类型 | 自有题目标 | 说明 |
|---|---|---|
| **记忆型**（公式/定理/性质/法则/判定/证明） | **6–8 道** | 需要多角度提取：正向用、逆向判断、变式应用、边界情况 |
| **理解型**（概念/关系/应用） | **4–6 道** | 理解一次就够，但要有不同情境的应用 |
| **技能型**（运算/解法/作图） | 3–4 道 | 靠熟练度，不是靠记忆 |
| **综合型**（跨点综合） | 2–3 道 | 本来就难，不靠题量 |

**为什么记忆型要 6–8 道**：一道正向题只能验证「套公式」，
一道反向题（"下列说法正确的是"）才能验证「记住了性质本身」。
两者不可互替。

## 五、入库策略（按证据强度，不搞一律锁定）

沿用 D31 的四级准入，但**记忆型知识点允许 `tag-mapped` 进诊断**——
理由：记忆型知识点的题 purpose 就是「练记忆」，
答案有官方解析支撑即可，不像理解型题那样需要严格唯一性。

| 等级 | 记忆型 | 理解型 |
|---|---|---|
| verified | 进 | 进 |
| cross-checked | 进 | 进 |
| tag-mapped | **进** | 不进 |
| ai-mapped | 不进 | 不进 |

## 六、题型多样性要求

同一知识点的题要覆盖不同「问法」，避免同一模板重复：

| 问法 | 作用 |
|---|---|
| 正向应用 | 常规套用 |
| 反向判断（"下列说法正确的是"） | 验证记住了性质本身 |
| 变式（换数字/换情境） | 验证不是死记 |
| 边界/反例 | 验证理解到条件层面 |
| 图形/图象 | 验证与表示形式的联结 |

**同知识点同一问法超过 3 道的，不再入库**——那是无效题量。
