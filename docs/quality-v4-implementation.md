# Quality V4 三批实施台账

本轮以 `9f0471009f13590beee850ca5dd4999ff64d14fd` 为基线，按照用户的八项标准继续实施。教师独立审核与真实学生教学效果验证继续暂缓。目标是完成当前登记的中国小学至高中数学材料与可运行学习流程；不将其改称覆盖所有 K12 学科或经过实证认证的课程。

## 三批交付

### 第一批：旧问题可追踪，学习资产可恢复

学习库升至 schema 4，迁移只重建必要的派生摘要，原会话、作答、作品修订及事件 JSON 保留。计划读取全部相关历史，不用前 1,000 条摘要截断旧问题。目标自评中的“还需补充”“需要重做”分别保留，不能因填写备注或新开会话而消失。

每项学习需要具有稳定身份、原资源版本、来源会话或作品、具体目标与后续观察。跨学段查看时仍能找到全部未解决事项。暂缓必须填写理由，随后可重开；一般新版本或一次无关答对不能清除旧问题。提示后的确认只可解决明确关联的支持事项，原错答不变，仍标明得到过帮助。

恢复页提供恢复码、完整加密备份、同一服务找回以及全新学习库导入。备份保留冻结内容、SVG、作品历次修订、帮助与曝光记录。冲突或损坏备份原子回滚，不覆盖另一档案；可读导出仍与可恢复备份分开。详细步骤见 [学习档案恢复](profile-recovery.md)。

### 第二批：完整基础材料、目标帮助与实际操作

保持原有 342 个核心主题与 135 个基础支持主题，补全全部基础主题的 270 项逐目标材料与自检。共新增 127 张完整卡，并重写原有 8 张基础卡；全项目达到 477 张完整讲解卡、954 项主题目标自检。保留的 50 张簇速查只作参考，不承担已承诺目标的完成计数。

每张新增或重写的基础卡提供具体解释、条件、表征、步骤、例题、误区及两个目标的自检量规；每目标补观察边界和“辨别问题—提示—修订”入口。适用范围包括数与位值、加减乘除、测量、几何、分数小数、统计和初高中基础内容。跨作者 AI 语义复核的实际发现与文件哈希保存在 `docs/reviews/`，不代称教师独审。

14 个专题单元的 104 项目标全部配置支持包，每项有一个辨别题、三个逐级提示、指导练习和至少两个真实的后续任务引用。支持活动保存过程与帮助记录，指导练习做对不能直接关闭原问题，最后的对应任务才产生有帮助的确认观察。复合目标仍标明观察不足之处，不能靠支持包数量假装所有目标已拆成微技能。

补 9 道具体阶段缺口任务，使单元阶段任务从 222 道增至 231 道，包括分数共同单位、概率补事件、函数不同尺度、往返方向、导数边界、比例等值和三角形反例。208 道辨别及指导微任务属于支持活动，单独统计，不重复充当独立评价题。

新增三个高中课程补充项目：模型比较、测量界限、概率模拟。21 项实践共 66 个目标、84 个步骤，允许保存、反思、量规自评与修订。新增项目明确是课程补充，引用真实主题位置，不伪造教材目录活动身份。

四种操作表征接入真实单元页面：十格与凑十、等值分数条、均值与截断纵轴、一次函数的表格和图像联动。操作状态及解释可显式保存、重新打开并随档案备份恢复；改变滑块不是自动得分。另补 4 幅精确 SVG，包括乘除竖式与不同坐标尺度的函数图。

### 第三批：明确范围、可审维护和固定版本验收

`data/curriculum_scope.json` 明确 1,124 项登记目标及其角色：954 项主题目标、104 项单元目标、66 项实践目标。课程范围页逐项给出解释、过程、任务、观察边界和修订路径，支持按学段、角色、关键词筛选。核心、基础支持、扩展分别规定完成条件，删目标或降格不会静默提高覆盖率。

题目准入改为显式、内容绑定的登记：3,568 条自有题档案的既有用途在本轮冻结。修改解释文字、答案或条件后，必须重新核对用途；仅增加解析长度或连接词不会自动升级为诊断材料。首次迁移明确保留原策略的暂定性质，没有把历史启发式结果包装成新的学科审核。

服务在启动时加载一致的课程目录、图、材料、单元、项目与图示。作者修改后应编译并重启，新请求不能在同一进程混用旧图谱和新教学卡。会话的冻结内容与评分版本另行保存，旧答案继续按旧记录解释。

变更审查从真实 Git 基线生成语义差异、受影响技能/任务/题族及页面预览清单，人工或 AI 审查记录必须绑定实际文件哈希。自动门禁只核查记录与版本，不替审查者判断数学正确。受影响页面在真实浏览器打开，检查实际内容、公式、图示、入口和手机布局。源码提交、发布清单、报告、日志与截图须绑定同一干净版本才可打包。

删除无调用的旧挑战题池分支，将 25 个历史写入脚本缩为明确拒绝写入的兼容入口，删除约 7,486 行不再运行的旧实现。另 5 个历史入口仅保留必要的只读适配或测试用纯函数，命令行仍拒绝写入正式作者源。30 个历史入口都有登记，不留下第二套可悄悄重建数据的作者流程。

## 明确保留的边界

材料齐备不等于教育效果已经验证。1,124 是当前登记目标分母，包含复合目标，不能当作中国数学课程全部原子技能的覆盖率。未分类旧题族、未知表征及未映射的细目标继续保留未知；不同题号不自动证明任务独立。纸笔、口头和实物活动的文字记录不独自验证这些活动真实发生。

学校账号、多人协作、云同步、公网部署和完整无障碍符合性不属于本轮本地项目承诺。它们没有被添加为阻止交付的新门槛。本轮明确完成的恢复、帮助、问题追踪和维护流程可在本地直接使用，教师与学生实证仍按用户要求保持暂缓状态。
