# 项目交接（Quality V6 全量恢复）

当前分支为 `codex/cnkg-quality-v6-followup`。本轮在远端已完成的32题、4卡和稳定选项修复上，恢复此前未提交的全课程材料工作，补齐全部登记目标的专属帮助、观察边界与明确任务关系，同时修正未作答先修推断、提示曝光和旧作品恢复流程。八项要求的实现与边界见 [V6全量恢复记录](quality-v6-completion.md)，当前数量见 [README](../README.md)。

本交接描述已实现的内容和维护合同，不代替最终验收报告。正式结果必须来自同一干净提交、同一发布清单的19项核心门禁和17条浏览器旅程；工作树中的专项通过或历史CI通过不能转写成当前提交已通过。独立教师审核与真实学生教学效果验证按用户要求暂缓，内容仍保留AI作者和待独立审核状态。

## 获取与运行

使用包含本轮提交的工作树、Git bundle或源码ZIP。在项目目录执行：

```bash
python -m pip install -r requirements-dev.txt
python tools/build_project.py --write
python web/server.py --port 8765
```

打开 <http://127.0.0.1:8765>。HTTP使用Python标准库，档案完整备份使用固定版本的 `cryptography`；构建与结构验收使用固定版本的JSON Schema依赖。源码ZIP不包含实际学习记录、运行数据库、`node_modules` 或未登记外部题库。

可重建内容使用 `python tools/build_project.py --check` 检查。完整固定版本验收需要真实Git基线历史；从bundle恢复、安装浏览器和打包的顺序见 [发布流程](release-workflow.md)。核心报告在 `build/regression_report.json`，浏览器报告在 `build/browser-check/report.json`；读取时先核对提交、发布清单哈希和完整检查集合。

## 编辑与构建

题源是23册 `data/content/` 和 `data/question_sources/application.json`；讲解、单元、实践分别直接编辑 `data/teach/`、`data/learning_units/`、`data/projects/`。稳定技能及旧任务契约位于 `data/skills/`。正式来源由 `data/content_sources.json` 登记。

编辑后执行 `python tools/build_project.py --write`。不要直接修派生的 `questions.json` 或 `catalog.json`，也不要再运行已封存的旧补全写入器。作者入口、契约归属和退役兼容规则见 [作者工作流](authoring-workflow.md)。

教材位置、技能和任务保留各自稳定ID。当前86项技能明确标为可观察，96项为复合、954项为旧复合；登记ID没有把旧综合目标自动拆成原子技能。增加后反求原量、减少后反求原量和从当前数量继续变化保留各自含义。4张远端已修卡及新增逆向加法身份没有被旧稿覆盖。

题族等价关系只写入 `data/task_family_aliases.json` 的显式审核记录，用于比较新旧曝光；不改写原事件。不进位与进位、直接求剩余与倒推原量等不同结构不能因泛化名称而合并。修改题面后须一起核对 `accept`、实际生效的答案契约和观察范围，不能只重算 `verify`。

## 学习判断与下一步

新诊断只为实际作答目标产生本次结论，未作答祖先保持未观察。旧版本 `assumed` 保留作历史原记录，界面标为“旧推断（未实测）”。先修关系是检查基础的路线，不是已有掌握证据。

学习计划按具体目标的实际记录安排先修入口。完成一个单元中的单道任务不会解除该单元其他目标的先修检查；计划可直接打开对应目标，再进入其帮助和任务。帮助后答对、同族重复和独立后续观察分开；缺少合适后续题时提供练习并保留待观察事项，不生成空检查或自动宣告解决。

104项目标支持都提供辨别、三层提示、指导与确认；其中27项具有作者写明的不同错误路线。提示曝光按当前实际展开的一层及选中路线的题族记录，不提前标记未展示的后续确认题或其他错误路线。老快照缺少这种声明时沿原来的有限归因规则解释，不借新版作者文件重写历史。

## 学习资产与恢复

匿名学习记录默认保存在 `var/learning.sqlite`，可用 `CNKG_LEARNING_DB` 指定其他位置。发布内容库是 `build/kg.sqlite`，两者独立；构建程序拒绝覆盖学习数据库。

逐目标自检分别保存原作答、困难辨别和重新尝试。打开帮助前先保存原过程，再记录对应版本的帮助曝光；记录失败不展示该提示，输入和重试入口保留。版本冲突不覆盖原草稿，历史作品使用原量规、帮助、参考和SVG快照。内容更新会显示当前材料入口，不用新答案批量重判旧记录；评分程序不兼容时明确说明续做限制。

作品、过程草稿、实践步骤、反思与自评有修订历史。自查按全部量规项目统计，未检查项或只写备注仍会提示；学生自评不改写自动判分。浏览器地址保留具体会话ID，刷新不再次创建检查。切换页面先处理未保存内容，输入框在原记录成功恢复后启用。

学习库使用事务维护派生索引，原始会话、作品、历史修订与事件JSON保持可追溯。导出schema 3包含已呈现题目的冻结题面、选项和图示，仍隔离未呈现题及尚未公开的反馈。该导出用于阅读核查；可恢复的完整备份从“档案与恢复”下载，以恢复码加密。换浏览器、清理浏览器和全新环境导入见 [恢复与迁移](profile-recovery.md)。

“待解决事项”保留跨会话、阶段、版本及学段的历史来源，暂缓须有理由。四种操作工具先记录预测，再检验并保存操作；限定方程案例保留逐步反馈和原配置。备份页区分生成文件、实际文件核验和最新资产是否一致，服务生成文件不等于用户已经保存。

## 审查与交付依据

本轮材料记录包含266道小学／初中答案变化的独立推导、534道变化题的有效评分合同核对、14张讲解卡和4个项目的深度语义抽样，以及全卡、全项目的结构检查。57个历史q95身份另有逐题目标与适龄复核，30条结构例外只对固定名单和完整内容指纹生效，旧生成器的随机两步检查继续保留；概率统计路线、题库恢复和诊断判断另有专门记录。证据索引见 [V6全量恢复记录](quality-v6-completion.md)。参考答案能被评分器接受只证明评分合同相容，不构成全题库数学语义全审。

课标摘录与旧ID保留在 `standards.json`，修订比较记录位于 `data/curriculum_comparisons/`。教材、课标和内容修订须保留来源、定位与内容指纹，AI复核和程序通过不升级为教师审核。复习按同范围最近完成及相关活动计算实际间隔；1／3／7天是当前产品规则，没有被称为已验证最优间隔。

正式发行包含 `source.zip`、`current-branch.bundle`、`evidence.zip` 和 `delivery.json`。bundle仅含当前分支引用及可达完整历史；学习记录和未绑定旧报告不进入证据包。使用 `delivery.json` 中的提交及SHA-256核对文件，远程同步以实际Git引用为准。本地提交、包名和验收通过本身不代表GitHub已经更新。

V5及前序V6修复文档保留当时范围与数量，后续交接以本页、V6记录和当前重算报告为准。
