## 实际内容与问题修正

小学对全部 355 项原不足目标提供具体的新观察任务，覆盖数字口读与手写、单位实际测量、同单位比较、数量重组、图形构造、统计图补画和口头解释。分段单价总价新增先划分各区间数量再乘加的结构，复用既有分段单价规范族；原固定单价过程任务保留。两项非标准数位重组确实要求在计数单位间重组，再恢复标准写数；其反馈中展示的旧方法另记参考曝光。纯算式输入按实际表示登记。有限曲线与线段的区别按直与曲、端点及相应对象范围解释，避免把“有有限长度”误说成线段独有性质。

初中补充实际区间限制的极值、有限墙长的围栏模型、余份与常数积一致性、双弦共半径、真实取值表和三视图、抽样框与未响应、频率合并及概率模型边界。新增题复用已有的余份、常数积与受限极值规范族；同一数学关系在不同学段不因换名字成为未见方法。证明、量测、作图另设真实过程任务，镜面测高补足共线与镜点居中的条件。

高中补充任意角的半角象限、多周条件、终边点坐标比、等步长增量比较、斜高与垂高区分，以及非零、退化、整数域、零分母和统计解释的边界。有限墙长题与初中对应模型使用相同规范族。数学归纳、向量几何、线面关系与函数作图等 30 个任务要求提交可查看的推导或图稿，数值／选择结果不代替过程。

本轮新增 12 张精确 SVG：小学 2、初中 6、高中 4，均实际渲染并逐张查看，核对数据、比例、方向与替代说明。图内字母及英文表头的中文含义写入可见题干，避免只在辅助说明中解释。给定静态图不称为学习者已完成操作；图稿和录音仍须真实提交。

## 审读范围和新门禁

416 个新增任务均有具体的 AI 作者逐题审读，另有 199 道客观题与 217 个过程任务的独立 AI 交叉记录。逐题判断包含数学推导、适用条件、观察边界与旧规范族比较；12 张图的真实字节也绑定审读。新增的 `check_assessment_reviews.py` 必须核对全部 416 条作者记录、199 条客观交叉记录与全部 1,039 个原不足目标，缺失、重复或过期即失败。

独立变异审计找出并修复了四类问题：报告行不能覆盖 AI 身份或虚称教师／学生验证；交叉理由不能只有空白或非文本；同一份报告不能同时充当同一题的作者与交叉审读；同路径 SVG 改动后不能沿用旧图审读。旧 1,912 个观察任务及其图示从确切 Git 基线冻结。原始与编译目录的一致性由先执行的编译门禁核对。17 个新增门禁回归与 4 个原状态回归已通过；独立审计的六个隔离探针符合预期。[工程审查](reviews/v9-review-gate-engineering-review.json) · [独立门禁交叉审查](reviews/v9-review-gate-cross-review.json)

旧题审读继续使用明确的历史批次：V7 的 908 道与 V8 的 2,676 道合计 3,584 道原题。V9 未重新逐题审查整个原题库，没有改动原题源；本轮读取的旧任务用于结构对照，不冒称全库再次审查。493 道隔离题保持隔离，1,731 道原暂定诊断用途保持。[原题历史索引](reviews/v8-bank-review-index.json)

正文数值扫描当前检查 7,453 处可完整解析的数值等式。原 27 处有意错误或矛盾只在原位置、原句和完整原任务均未变化时续接；其中 14 处因作者源追加新题重绑整文件指纹，13 处源字节也未变。本轮新增未处理异常为 0，未按关键词批量跳过。[数值反例续接](reviews/v9-numeric-counterexample-review.json)

## 验收与主分支合并

完整发行要求同一干净提交、同一发布清单完成 22 项核心门禁和 18 条真实浏览器旅程，共 23 项顶层门禁。原图稿／录音保存旅程另加入三学段 V9 新题的确切目标、阶段、真实图示、390px 布局和观察结果检查；全部受影响页面须实际打开。合成作答只验证产品行为。源码、当前可达历史与完整证据包必须逐文件核对，并实际恢复 Git bundle。

PR #1 已改为以 `main` 为目标。本页记录实现和验收要求，最终是否通过须读取该固定候选的 CI、GitHub 合并预览与交付证据；历史通过不替代本轮结果。合并前复查 main 与候选 head，并核对合并预览的树。应使用普通 Merge commit，使语义审查引用的真实 Git 基线继续在 main 的可达历史中；不要通过 squash／rebase 丢失所需历史。[合并准备](reviews/v9-main-merge-preparation.json) · [发布与恢复](release-workflow.md)

教师独立审核与真实学生效果验证按用户要求暂缓，仍分别记为未完成，不阻断已授权的工程与材料维护。AI 审读、程序通过、合成浏览器答案和资源数量不产生这两类证据。剩余 1,011 项客观族不足也不因合并而改称完成。
