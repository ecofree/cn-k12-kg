# Quality V5 课程对齐范围与剩余缺口

当前是中国小学至高中数学的本地学习项目。范围包括23册、477教材导航点；核心342点、基础支持135点，另有21项可选实践。课程标准条款与教材位置另行维护，章节、单元、目标、题目不混成一种覆盖率。

## 保留完整分母

| 目标层级 | 登记数量 | 本轮加强审查 |
| --- | ---: | --- |
| 教材主题目标 | 964 | 42主题、94目标自检、251活跃题逐项核对 |
| 深入学习单元目标 | 104 | 14单元逐目标先修、材料与任务入口；同结构题族和实际表征核对 |
| 可选实践目标 | 66 | 保留作品、过程、量规和修订要求，本轮未声称全部项目语义升级 |
| 全部稳定目标身份 | 1134 | 加强范围198项；不同层级仍分别解释 |

新增的10个可观察主题目标用于拆出计数与符号、读写、多面体高度与体积、三角形特殊线段等实际行为。原有复合目标及其稳定身份保留；84个可观察目标、96个复合目标、954个旧复合目标分别标记，未将改标签当作完成原子化。

## 当前可重算的条件

执行 `python tools/check_alignment.py --check`，或在网页“课程范围与目标”中按缺口筛选。`data/alignment_targets.json` 明确本轮加强验收范围；该范围以外的目标不会被删除、降格或自动标成已审查。

| 条件 | 当前具备 | 仍需补充 | 解释 |
| --- | ---: | ---: | --- |
| 目标专属帮助 | 510 | 624 | 作者明确写出具体困难的辨别、提示及修订，或已有目标支持/项目修订路径 |
| 作者写明的观察边界 | 510 | 624 | 说明任务实际观察什么、不能据此确认什么 |
| 对应任务有已核对题族与表征 | 198 | 936 | 不把未知表征、题号变化或模板文字算成已核对 |
| 多种客观任务结构 | 102 | 另列机会不足 | 仅用于安排自动后续观察；口头、作图、证明与建模仍需要过程作品和量规 |

这些数量是资源与关系条件，不是教学质量评分、课标完整覆盖率或教育效果。字段非空也不能单独证明解释适龄、题义正确或指导有效，必须与逐题审查、数学反例和真实页面一起看。

最终全量核对另将 `m8b.22.2-q102` 的明示差额读取、`mh4.5.3.1-q102` 的已给位置代入，从不符合题面要求的advanced改为basic。这两个主题的现有应用题组继续保留真正扩展任务不足的缺口；设计档位不等于真实学生难度，不能为保持数量配额给简单任务贴高级标签。

## 八项要求在本轮的落实

| 要求 | 已落地机制与材料 | 仍需明确的边界 |
| --- | --- | --- |
| 范围明确 | 固定目标身份、三类内容完成要求、全量缺口与加强范围分开显示 | 全部全国原子技能尚未逐项登记；旧复合目标继续保留 |
| 材料能教 | 42主题深入核对，补实际图表、条件、反例与94项自检 | 其他主题的完整结构不能代替逐项语义质量审查 |
| 题目说明问题 | 251题核对有限观察用途；第二批撤去99项诊断、152项整主题确认权限；含第一批总计101项、154项 | 大量范围外旧题仍需逐题核对；局部正确不代表整个主题掌握 |
| 错误后有帮助 | 逐目标帮助入口，五个重点支持按不同错误进入实际指导分支 | 其余支持仍以固定指导流程为主，不宣称全部困难都有自适应路线 |
| 后续任务有依据 | 精确目标/任务入口、真实题族/表征/帮助曝光和间隔；复合参考记录多题族 | 未分类题和未知表征不能提供新的独立观察；有记录不等于已证实独立掌握 |
| 未解事项保留 | 原事项、支持修订与帮助后独立确认分开；版本、阶段、会话变化不能清空 | 仍以明确绑定的具体后续证据更新，不凭单次正确或自评解决全部问题 |
| 学习资产恢复 | 恢复码、加密完整备份、文件核验、精确新鲜度/容量/兼容提示；旧快照保存 | 用户仍须实际保存文件与恢复码；不声称已经自动云同步或完成所有真实异机演练 |
| 维护可持续 | 语义变更清单、逐项审查、实际受影响页面预览、当前固定提交验收与发行包 | 历史通过不能转移到新版本；AI核对不冒充教师或真实学生证据 |

## 对标市场产品时采用的能力

功能参考来源与核对日期见 [三批计划](quality-v5-plan.md)。本轮借鉴清晰目标与任务连续性、基于观察的后续行动、预测后操作、多表征比较、限定范围的分步反馈，并用自己的数学内容实现。

现在可以按目标进入对应材料与所选题目；在四个操作工具中保留原预测、错误预测、点数和解释；在三个一元一次方程案例中比较解集与操作理由。它们构成可实际使用的学习流程，但不能据此声称已达到 Khan Academy、IXL、Amplify/Polypad 或 GeoGebra 的整体内容深度、交互广度和运营成熟度。

后续提升应优先补齐上述624与936项的真实内容条件，将高价值的困难分支和过程活动扩展到更多目标，再按明确产品需要考虑班级/教师工作流、账号及云同步。教师独立审核与真实学生效果验证继续按用户要求暂缓，不作为当前交付阻塞项，也不计为已完成。
