# Quality V3：统计学习链与已确认内容修正

日期：2026-10-26。基线：`a7988876eeb61ebfd5841c4f883170289d11c25e`。本页记录本轮内容范围；最终验收及发行提交以该轮实施台账和生成报告为准。

## 为什么补这条链

V2 已有统计主题的教材导航、完整讲解卡和实践活动，但 11 个可保存分阶段作答的学习单元中没有统计单元。因此本轮补的是“读图与平均数 → 抽样与波动 → 相关与拟合”的连续学习经历，不把已有统计资料说成完全缺失，也不把新增三个单元说成整部统计课程已经覆盖。

设计先确定需要回答的问题、数据从何而来、怎样分析、结果可解释到哪里。作为设计参考，ASA 的 [GAISE II（2020，官方 PDF）](https://www.amstat.org/asa/files/pdfs/GAISE/GAISEIIPreK-12_Full.pdf) 强调这四个环节，并以 A、B、C 展示统计推理的发展层次；这些层次是能力进阶，不能机械等同于年龄。本项目的题目、数据与图示为本轮独立编写，没有复制该报告中的题目、插图或数据集，也不分发该 PDF。

中国课程的定位继续使用仓库已有的课标条款与教材点。小学引用 `cms-2022:2.SP.01`、`cms-2022:3.SP.01`，初中引用 `cms-2022:4.SP.01`，高中引用 `cms-2017:H.PS.05`；课标版本和摘录范围沿用 `standards.json` 与现有修订对照记录，不额外宣称课程认证。

## 任务类型与数学反例

本轮分别安排了读取、计算、反例、条件检查、方案说明与结论改写。典型任务包括：

- 条形图从 16 本截起，实际 18 本与 20 本被画成可见条长 2 与 4；学习者须解释为什么实际本数不是两倍。
- 两组人数不同，先还原总量再合并。后续题用 2 人平均 8 本、6 人平均 0 本，得到整体平均 2 本，不能把两个组平均数直接平均成 4 本。
- 缺失的一天与已记录的 0 本分开处理；不能暗自补 0 后声称求得完整五天平均。
- 同均值、同极差的数据仍可能有不同方差：`0,5,5,10` 的方差为 `12.5`，`0,0,10,10` 为 `25`。
- 将从运动社团抽到的人数扩大，仍不能自动使样本代表全校；随机名册中不回答的人也不能默默用身边方便的人替换。
- 五点 `(-2,4),(-1,1),(0,0),(1,1),(2,4)` 的 r 为 0，但全部满足 `y=x²`。变量全为常数时 r 则未定义，两者不能混为一谈。
- 两点 `(1,3),(2,4)` 的 r 为 1；若强制过原点拟合 `ŷ=2.2x`，按题面明确的中心化定义 `R²=1−SSE/SST` 得到 `−0.6`。这说明 `R²=r²` 不能脱离含截距的一元最小二乘条件使用。
- 观察到正相关、得到较高 R²、正确代入预测式，均不能单独证明干预效果、人数命中率或远距离外推保证。

例题与任务依数学结构保留题族身份。只换数据仍是同族；主页面提供过的图、例题与参考内容仍按曝光记录解释。新题的 `transfer`、`delayed` 名称不自动产生“未见过”“已经独立验证”或“满足真实间隔”的结论。

高中拟合例题使用 `(0,2),(1,7),(2,6)`，给出 `b=2,a=3` 和中间点正残差 `2`；相应迁移计算使用不同数据 `(1,2),(2,4),(3,8)`，给出 `a=−4/3`。残差读图题保留观测与预测位置，图中不直接印出所问的残差计算结果。它们仍共享相应数学题族，不被登记为已证明相互独立。

两道空间题原本没有存储证据级别，会按解释文本动态分级。`m3a.1.2-q3` 现在明确按排除候选、检查球、得出结论的顺序说明，仍为 explained。`m9b.33.2.2-q5` 补充排除依据后，当前文本由 bare 提升为 explained；这是解释信号变化，不代表诊断准入已经获准。作者源明确设置 `diagnosis_eligible=false` 和 `for_diagnosis=false`，保留基线的仅练习用途。两题的证据信号由正常流程计算，没有把更完整的解释伪标成 bare，也没有据此升级独立审核状态。

原作者源为 `data/content/sanshang.json`、`data/content/jiuxia.json` 与 `data/question_sources/application.json`；派生题库和目录由正式构建工具重建。修正的基线、字段及前后指纹由 `data/migrations/quality-v3-corrections.json` 记录。

## 细目标与原课程的关系

下表中的目标索引从 0 开始，与旧教材点 `mastery_criteria` 的真实序号对应。refines 表示细化其中一部分，不表示做完一个细目标就覆盖整条旧复合目标。

| 新目标 | 可明确对应的旧教材目标 |
| --- | --- |
| 小学 `read_scale` | `m4a.6.1[0]` 读懂单式条形图 |
| 小学 `mean`、`combine` | `m4b.6.1[0]` 计算一组数据平均数；合并平均是具体变式 |
| 小学 `choose_chart` | `m6b.2.1[1]` 比较扇形图与其他图特点 |

| 初中 `sampling` | `m7b.12.1.2[1]` 判断抽样代表性 |
| 初中 `centre` | `m8b.24.1[0,1]` 集中趋势计算与选择中的均值、中位数部分；未借此声称众数全部覆盖 |
| 初中 `spread` | `m8b.24.2[0,1]` 方差计算及比较 |
| 高中 `correlation` | `mh5.8.1.2[0,1]` 线性相关强弱方向与 r=0 的边界 |

| 高中 `residual` | `mh5.8.2.1[1]` 计算残差 |

小学 `limited_claim`、初中 `inference`、高中 `r_squared` 与 `prediction_limits` 没有足够精确的单条旧目标对应；它们保留自身身份及教材位置，不为了填满字段虚构旧目标等价关系。

经内容关系检查的先修建议是：小学合并平均需要平均数；初中抽样需要先明确总体与样本，集中趋势和方差需要平均数，推断需要对象范围与抽样方式；高中相关解释需要集中趋势与波动基础，最小二乘参数计算需要均值，R² 解释需要相关与残差，预测边界需要样本推断和残差。残差题在给出预测值时即可完成，不强制先学完整最小二乘推导。稳定技能链接最终写入登记表，由目录校验器检查引用；这些关系用于建议，不阻止学习者直接进入内容。

## 内容验收及保留边界

`tests/test_quality_v3_content.py` 包含 15 项回归，重点是上述真实反例与答案边界：

- 独立有理数重算均值、方差、最小二乘参数、残差与中心化 R²。
- 检查 `2/3` 接受 `4/6` 而拒绝未声明近似的 `0.667`；残差符号和残差平方不能混用。
- 检查相同均值允许组人数不同，避免把常见充分条件错误写成必要条件。
- 检查零相关曲线、未定义相关、分位数尾部比例、单向逻辑条件与候选立体边界。
- 检查两道空间题在如实计算解释证据的同时，保留基线的可诊断／仅练习使用范围，防止加一句推导连接词就自动获得新用途。
- 检查 11 道修订应用题的派生核验字段与当前解释重算一致，避免解释改了却保留旧字数或匹配计数。
- 检查每个新目标都有各阶段任务，全部 26 道自动判分任务的参考答案可被接受，19 道量规题仍保留过程评价状态。

单元检查与这些测试已在开发过程中通过。它们证明相关反例、结构和可复算条件已被检查；不证明整个数学课程语义穷尽，也不代替教师独立审核或真实学生教学效果。后两项继续依用户要求暂缓。
