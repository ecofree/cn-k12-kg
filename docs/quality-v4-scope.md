# V4 课程范围与逐目标证据目录

范围保持为中国小学至高中数学的现有 23 册、477 个教材位置。原角色不降格：342 个核心主题有 684 项登记目标，135 个基础支持主题有 270 项目标。14 个专题单元另有 104 项细目标，21 个项目另有 66 项目标；总目录共 1124 项。主题目标、单元细目标与项目目标分别统计，不能相加后声称扩大了国家课程覆盖率。

## 三类完成要求

| 角色 | 对学习者的要求 | 对作者材料的要求 |
| --- | --- | --- |
| 核心学习 | 在所选课程范围学习所有登记目标，保留作答、修订和仍待确认的问题；必要时继续观察迁移与间隔表现。 | 每个目标有解释、实际学习过程、明确任务与评价依据、练习和修订入口；专题单元另外配目标支持及练习、迁移、间隔阶段任务。 |
| 基础支持 | 因前置要求或实际困难进入；理解基础意义并完成对应任务，未解决的事项继续保留。 | 基础内容同样需要逐目标材料。簇速查只能辅助，不能代替具体解释、自检或把目标从分母中删去。 |
| 扩展活动 | 是否参加可以选择；参加后留下过程、作品、量规自评及修订。不要求每个学生完成所有扩展项目。 | 每个项目目标有对应步骤、成果、量规和反馈修订路径；数据、推断及实际操作的边界需明确。 |

“材料齐备”只表示作者资源按约定结构存在并可定位，不等于教师审核通过、真实学生效果验证或某个学生已经掌握。教师审核与学生效果验证继续暂缓，其状态不得由自动检查改成通过。

## 目录与检查

`data/curriculum_scope.json` 固定稳定技能 ID、原目标文字、角色和所属资源。常规检查读取实际教材目标与资源，比对清单；目标删改、降格、遗漏和新增都需要显式处理。即使清单过期，报告仍展示当前来源中的全部目标，不会藏掉新增或缺材料的目标。

```bash
python tools/quality_scope.py --check --json build/quality-scope.json
python tools/quality_scope.py --check --require-complete
```

只有在审查过范围变化后，才使用 `--write-manifest` 更新清单。作者补卡不会改变目标分母，无须重登记范围。

每个目标行给出材料、学习过程、任务、观察边界和修订路径。引用包含资源文件、JSON Pointer、内容 SHA-256 和相应 API 地址，便于打开实际内容和固定版本核对。目标绑定只接受显式 criterion_index/title 或 objective_ids；同主题题目保留为辅助练习，不冒充目标证据。缺口列出具体代码，不能由手工填一个 `complete=true` 清除。

## 本轮基础目标核查起点

基线 135 个基础支持主题中，小学 124 个／248 目标，初中 8 个／16 目标，高中 3 个／6 目标。8 个小学旧完整卡仍没有逐目标行；270 项基础目标因此全部缺明确的目标材料与自检映射，尽管一些簇速查或相关专题已有可用内容。详细分组由报告的 `groups` 自动列出，随实际补充重新计算，不把本段基线数字当作当前缺口。

初高中 11 张基础卡已新增 22 项具体目标解释、自检与量规，并附观察边界、辨别问题、提示和修订入口。其中特别区分：有理数按数值分类与写法；0和负数距离；连续舍入的误差；抽样框和未回复；简单随机抽样的样本等可能与个体等可能；分层配额与层内随机；列联表的条件方向；三视图的实际作图与只会回答面积题。例题与自检仍是作者材料，具体数学反例和计算另有回归测试。

小学数的认识组另补 24 张卡、48 项目标：从逐物点数、读写、配对、序数方向、数的分合，到十与百的换组、含0读写、算盘、中文四位分级、准确改写与近似、正负方向约定。操作、口读和手写目标要求留下相应过程，文字输入不冒充这些行为已经被系统直接观察；程度词“大一些／大得多”也不设虚假的统一差值阈值。

运行时可用 `cnkg.quality_scope.build_scope_report()` 提供相同的完整报告。报告进行全卡检查和例题复算，适合构建时生成或按内容版本缓存；不要对每次按键重复运行。

本轮其余53张算术卡和47张几何、测量、统计、分数小数等基础卡已补齐；现有135个基础主题的270项目标均有明确材料、自检、观察边界和困难修订支持。实际范围与引用仍由检查工具重算。
