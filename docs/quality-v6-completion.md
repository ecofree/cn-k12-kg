# Quality V6：全量恢复、已实现行为与验收边界

## 本轮接续了什么

本轮从远端 `652bf63212044e50e259f207f650a8d6f0b2b132` 继续，将此前基于V5 `829f5ddf1c9fb548b2b43e3b68463e3879dcd3b0` 留在工作区的全课程草稿重新审阅、合并和修订。前序V6已完成的32题、4张讲解卡、逆向加法新身份及稳定选项顺序保留，没有用旧稿整体覆盖。

恢复范围包括23册作者源、全部477张完整讲解卡、14个单元和21项实践；其中472张卡相对远端基线有实际变化。全课程范围没有缩成少数重点主题。新增内容、历史源、稳定身份和学习记录按各自版本保留，教师独立审核与真实学生实测继续按用户决定暂缓。

本文中的“完成”指本轮恢复、功能与可审查证据已经落实，不表示全部课程已获学科认证或学习效果已经验证。最终发行结果必须查看当前干净提交绑定的报告；正在修改的工作树、专项测试和历史通过记录不替代该结果。当前开发分支是 `codex/cnkg-quality-v6-followup`。

## 实际修复及其理由

### 材料与数学条件

恢复时保留四张远端已修卡的语义、稳定目标和任务身份。5以内减法与逆向加法明确区分“求剩余”和“已知拿走及剩余求原来”；历史增加后求原来的减法对照保留，使用14−4=10及10+4=14验证，避免让本课先掌握之后才系统学习的退位算法。

六道新增分式任务观察化简、原式禁值、最简公分母与合并分子：例如 `[(x²−9)/x]÷[(x−3)/x]` 化简为 `x+3`，仍须排除0和3，不能把仅使被除式为0的−3也排除。多项式与数集使用明确作者合同，不用启发式推断覆盖。纸上写出的限制若未提交，不由只填化简结果的自动判分宣称已观察。

逐题核对还发现了数值自洽无法发现的问题。原“一根绳分8份，甲取6份乙取3份”虽然比较分数的答案为6，故事同时取9份不成立，现改为两根等长绳分别比较。应用题解析 `25+20−8=25` 改为37；把零误排除在非负数之外的表述已修正：零既不是正数也不是负数，同时属于非负数和非正数。直方图坐标轴补上 `fill="none"`，避免开放路径默认填充遮住柱形。

477张讲解卡的966项目标及21项实践的84步骤、66目标都执行结构与引用检查；45个退役题入口从当前卡片移除，退役原题保留。门禁现同时检查ID存在与实际练习准入，退役来源优先拒绝，避免“历史还在”被误当“当前可练习”。[材料恢复审查](reviews/v6-materials-recovery-review.json)

### 评分合同与目标映射

与远端基线重新比较，实际有267道题的答案变化，其中266道小学／初中题均有从题面重新列式的独立推导，未把作者 `verify` 与 `answer` 相符当作外部证据；六道新分式题另给代数及定义域理由。534道题的题干变化，题干、答案、`accept` 或有效评分合同变化的审查并集也为534道，逐一读取实际生效的author／binding合同。

246条旧 `accept` 已清理；位置题改问P到Q经过几个间隔后，残留“第三列／3列”会被评分器误判正确，因此不仅检查新答案能否通过，还核对旧别名是否应被拒绝。柜边估测答案改为60厘米时，旧小数形式合同会拒绝整数60，现已修正；另外九题新增的整数或小数要求已同步绑定。

目标映射按实际提交行为收窄。识记名称、代入已给公式、填写一个分子或计算一个边界，都不能自动代表建模、完整推理或全部目标已观察。撤去过宽映射会增加“未映射具体目标”的真实缺口，但保留原题和作答用途，不借错误映射提高覆盖率。[题库恢复审查](reviews/v6-bank-restoration-review.json)

### 历史“两步题”的实际目标

本轮逐条复核57个历史 `q95` 身份，其中56题相对基线有变化；稳定的题号后缀不决定现行任务必须包含几个运算。5以内分与合、整千整百数组成、同分母分数比较等目标，需要先检查任务实际观察的行为，不能为维持“两步”标签再添无关计算。原两根等长绳的 `6/8` 与 `3/8` 比较改为基础设计等级；另外三道数位组成或单位1补足题同样纠正原进阶标签，其他难度也明确为未经学生数据校准的作者设计。

现行30条例外均有独立列式、适龄及目标理由、观察边界和完整作者对象指纹。固定名单以外继续执行原两步要求；内容有变化时旧例外失效。57个历史生成器及其原有随机结构、数值验算检查保留。`m2a.3.7-q93` 与另一题完全重复的题面改为“15个苹果，每3个一袋”，由15÷3=5得到袋数；保留原等量分组题族，换数值不算新增结构。专项9项测试已通过；这项结果不替代正式全套验收。[逐题审查](reviews/v6-step-task-review.json)

### 先修、题族曝光与历史

新诊断不再因后继题答对而给没有作答的祖先生成 `assumed`；共享先修也不会因此被其他目标的后续回溯跳过。旧 `assumed` 状态仍在原记录中，界面注明“旧推断（未实测）”，当前计划不从旧状态补造作答证据。

计划分别处理单元活动和具体目标观察。完成抽样单元中一个抽样目标任务，不能抹去尚未观察的波动目标；计划仍提供“检查这项前置目标”的准确入口。跳过、未公开反馈、旧版本答题或只完成容器不自动解除当前目标的检查；真实答错或有帮助的回答仍作为带原结果和帮助属性的观察保存。[诊断与先修审查](reviews/v6-diagnostic-observation-review.json)

题族改名只通过具体结构核对建立等价比较，不改写旧事件。已见方法不会因换名而成为“未见”；继续当前数量与倒推原量、进位与不进位不能因泛名而合并。等价名称合并也参与多题族计数，避免用不同名称重复计算机会。[题族别名审查](reviews/v6-family-alias-review.json)

概率与统计新增22项分支支持，针对独立与互斥、条件抽样、名单覆盖、频率与概率、均值及离散程度、相关与回归等具体错误设置不同任务。当前提示只记录本层实际提供的结构，未选错误路线、未展开提示及后续确认题不提前算作曝光。历史快照没有精细声明时，使用原来的有限归因，不从新版来源补写历史。[概率统计路线审查](reviews/v6-probability-statistics-routes-ai-review.json)

### 先保存，再提供帮助

自检作品保存原回答、困难辨别和重新尝试三个部分。打开帮助先保存原作答，再记录对应版本的帮助；服务未确认记录时，提示保持关闭并保留输入。参考、指导和答案各自留下曝光，不把“已提供”写成“已理解”。

恢复历史作品时仍显示原帮助与参考快照。当前材料变化时，旧会话可以提示新版入口，但旧答案、旧评分合同及已保存观察不会用新版本重判。评分程序不兼容时阻止继续判分并说明限制，原记录仍可查看。备份、导出、作品修订和待解决事项继续保持原有所有者隔离及版本语义。

## 发布验证的实际边界

正式验收执行19项核心门禁，`--with-browser` 另加入浏览器门禁，共20项；浏览器内部必须执行17条旅程。新增完整数值等式门禁检查解析和参考，不限于答案字段；故意错误示例要有显式语境审查，不能作为整类忽略规则。

本轮新增两条真实界面旅程：`goal_support_revision` 验证原作答先保存、帮助记录失败保护、辨别与修订恢复、冻结参考和内容更新提示；`prerequisite_plan` 验证单个目标的完成不会隐藏未作答先修、准确目标入口及旧推断标签。它们使用合成作答，内容更新提示的界面夹具和HTTP真实版本检查在报告中分别说明。

本文不预写本轮全套门禁通过。最终以 `build/regression_report.json`、`build/browser-check/report.json` 及绑定该提交的CI日志为准，核对提交、清单哈希、干净状态、检查集合、实际预览页面和日志／截图指纹。修改发行文件后须重新生成清单、提交并验收；专项运行、旧报告或部分旅程不能制作正式证据包。具体命令见 [构建与发布](release-workflow.md)。

## 仍需保留的限制

当前全量对齐快照为：

| 缺口 | 数量 | 对使用的影响 |
| --- | ---: | --- |
| 活跃题族未知 | 633／3,091道 | 不能按不同题号声称获得独立新结构 |
| 活跃题表征未知 | 637／3,091道 | 不能自动判断表征迁移 |
| 活跃题未映射具体目标 | 844／3,091道 | 保留主题定位，不能将它们计为具体技能观察 |
| 多客观题族不足 | 670／1,070项主题和单元目标 | 400项具备至少两种登记客观题族；其余自动后续安排仍受限 |

前三项集合可重叠。多客观题族统计已合并经审查的等价名称；66项实践目标及其他过程目标继续依据作品量规，不为凑数强制客观题化。1,136项目标有帮助与任务关系并没有清除这些任务级缺口。当前数字可用 `python tools/check_alignment.py --check` 重算，改变映射或别名后应同步更新。

104项目标支持中77项尚未具有按不同错误切换实际指导任务的分支，仍保留各自辨别、提示和默认指导。旧复合目标需在后续具体内容工作中继续细化。实际中文排版、可达性与内容质量只能按当前报告列出的检查范围陈述；本地SVG渲染的CJK字形限制不冒称完整视觉验收，手机与键盘定向回归也不代表完整无障碍符合性。

教师独立审核和真实学生教学效果验证继续暂缓，没有虚构教师签字、学生样本、学习增益、长期保持率或实测难度。本轮保留这些状态，同时把已获授权的材料、工程、恢复及持续验收工作继续完成。
