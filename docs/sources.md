| 教材改版时间线 | 2024 秋一年级与七年级、2025 秋二三年级与八年级、2026 秋四五六年级与九年级启用新版 | 因此 2026 年 10 月：小学四下/五下/六下、初中九下仍是 2027 春才发布 |

**课时对不齐的地方**：七下按章合计 62、官方总课时 65；八下 64 vs 67。差的 3 课时大概是「综合与实践」少了条目，但抓到的目录页没有列出，因此 `outline.json` 里同时记 `total_hours` 与 `allocated_hours`，把差异留在数据里，不硬凑。

**九下 / 四下 / 五下 / 六下为什么没有点**：这四册都属 2027 春版，尚未发布。九下按官方结构表保留了 4 个章名与课时，其余三册连章名都没有，只在 `outline.json` 的 `pending_volumes` 里登记。教材面世后，用 `tools/fetch_toc.py` 加一行书号重跑即可。

**高中为什么是 2019 版**：人教 A 版高中数学目前仍是 2019 版（依据 2017 版课标 2020 修订），没有随义务教育一起换 2024 版。因此每条知识点的 `curriculum_version` 按册次区分，校验器会比对。

## B 级：结构化推导，逻辑可复核

| 内容 | 做法 | 复核方式 |
|---|---|---|
| 知识点切分粒度 | 一律切到教材最小小节（如 1.2.4 绝对值），不合并、不拆细 | `outline.json` 的叶子与 `topics.json` 一一对应，`validate.py` 双向校验 |
| 先修边 | 教材编排顺序 + 数学逻辑依赖；"不会 B 就学不了 A"记 hard，"有帮助但非硬门槛"记 soft | 每条边都写了中文理由，逐条可反驳；39 条边无环、无悬空 |
| 根节点 | 七上两个起点：正数和负数（代数线）、立体图形与平面图形（几何线） | 小学阶段只学过自然数与直观图形，无初中先修点 |
| 知识点类型 | conceptual / procedural / reasoning / application / modeling | 与课标"了解—理解—掌握—运用"的行为动词大致对应 |

## C 级：待核，不要直接引用

| 内容 | 现状 | 补法 |
|---|---|---|
| 课标条款编号 `cms-2022:4.NA.01` 等 | **本项目自定编号**，不是官方编号；`band=4` 表示第四学段（7–9 年级） | 若要引用，用官方条款序号替换，并在 `source` 里写明页码 |
| 课标条款摘要 | 自撰概述，`verbatim: false`，`page_or_ref: "待核"` | 对照《义务教育数学课程标准（2022 年版）》第四学段"内容要求"逐条核对原文 |
| 掌握标准 `mastery_criteria` | 按"可观察的行为"写，但未经验证 | 请教师改成课堂可观察的动作 |
| 题目难度 `basic/standard` | 主观标注，没有学生数据校准 | 用答题正确率回填；现在每点 2 道 basic（入口档），仍未经学生数据校准 |
| 骨架点的 `domain` / `theme` / `type` | 由章名、节名关键词推断（见 `tools/scaffold.py` 的 THEME_RULES / TYPE_RULES） | 填内容时逐条复核；小学按单元建点，推断准确率最低 |
| 先修强度 hard/soft | 主观判断 | 教师审核 + 学生错题共现分析（先修点错→后继点也错的比例） |

## 明确没有使用的东西

- `xiaoyang111222/cn-math-taxonomy` 的任何数据（CC BY-NC，且对齐 2012 版旧教材）
- `withmarbleapp/os-taxonomy`（ODbL，但内容是欧美课标，与国内教材不对应）
- 任何商业教辅的题目与解析

## 参考过的项目（仅用于结构设计）

| 项目 | 借了什么 | 没借什么 |
|---|---|---|
| `xiaoyang111222/cn-math-taxonomy` | 字段划分、hard/soft + reason 的边模型、2 题判定与祖先推断的思路 | 全部数据、代码 |
| `withmarbleapp/os-taxonomy` | JSON Schema + manifest + SHA-256 的工程化做法、`centrality` 之类的元数据意识 | 数据（英文课标） |
| `learning-commons-org/knowledge-graph` | "标准化 schema + 多入口交付"的产品思路 | 数据、API |
