## 状态如何保持可核对

`comparison_status: complete` 表示有实际比较记录；`status: pending_review` 表示独立审核尚未完成。
这两种状态可以同时存在。独立教师审核按用户要求暂缓，不阻断本轮材料完成。

每项记录包含：旧摘录哈希、新版文件哈希、PDF一基页码、印刷页码、段落范围、差异分类、具体结论及受影响材料。
扫描件OCR用于检索；公式、上下标、跨页句、例号和选学脚注的歧义需回看原页。

```bash
python tools/curriculum_compare.py --write  # 从已完成的比较记录同步版本登记
python tools/curriculum_compare.py          # 校验哈希、页码及结论绑定
python tools/coverage_report.py --check --require-complete
```

完成标志必须与 `data/curriculum_comparisons/` 中的同一条款一致。
缺文件、基线摘录变化、错误PDF哈希、超出页数的定位、只改登记结论都会被拦截。
若已有独立批准，自动同步工具拒绝覆盖，需要先核实批准所对应的具体版本。

## 后续内容更新的工作流

1. 保留旧ID及已发布内容；登记新版全文来源、哈希和准确定位。
2. 逐段比较要求动词、数学对象、参数条件、适用范围、选学边界与学段安排。
3. 同步受影响的目标、讲解、例题、练习和量规，保留具体材料引用。
4. 重建登记源与发布清单；旧会话仍使用原题目和评分版本，不能用新答案重判旧提交。
5. 只有真实教师或学科专家的独立记录才能将审核升级为 `reviewed`；AI比较和程序通过不能代替。

## 覆盖报告的分母

| 层面 | 当前分母与含义 | 不能据此推断 |
| --- | --- | --- |
| 教材导航 | 477个实际目录节点 | 每个节点都只有一个细技能 |
| 核心讲解 | 342个core；全部有完整卡 | 一张卡涵盖整部课程所有相关知识 |
| 核心目标 | `topics.mastery_criteria` 的684项 | 这是全课程所有可拆微技能的穷尽总数 |
| 分阶段细目标任务 | 10个单元、30目标、76任务 | 30除以目录节点数是课程覆盖率 |
| 综合实践 | 原目录18个活动；全部有材料 | 有材料就已证明学生掌握 |
| 独立教师审核 | 内容版本绑定的真实批准记录 | AI复核等于独立审核 |
| 学生证据 | 经审核的真实试点与可比任务 | 演示日志等于真实教学成效 |

工具点保留速查参考；速查或单元关联不会替代核心完整卡与逐项目标材料。
已登记目标与全课程所有可能微技能是两个口径，后者未设置虚构分母。

## 综合实践材料

原目录18项均有原创材料，包含操作步骤、学生交付物、数学条件、参考过程及人工量规。
