# 课标版本与教学覆盖工作流

## 已登记的范围

现有 `data/standards.json` 的 78 条项目记录仍以义务教育 2022 年版、普通高中
2017 年版 2020 年修订为数据基线。项目摘要与定位的课标原文摘录分开保存。
教材的 2024/2019 版本标记不能代替课标版本，更不能表明已完成新版逐条核对。

`data/curriculum_versions.json` 登记了 2025 修订版的存在证据：

- [课程教材研究所](https://www.ictr.edu.cn/policy/cheng/p/12.html)列出了高中数学
  2017 年版 2025 年修订的解读条目（2025-12-04）。该页面是版本存在证据，
  本次没有取得完整新版数学课标正文。
- [广东省教育资源公共服务平台的名师工作室资源页](https://zy.gdedu.gov.cn/studio/index.php?id=75215&r=studio/post/view&sid=621)
  （2025-11-20）列出义务教育数学 2022 年版 2025 年修订的 PDF 题名。本次只核到
  题名和附件登记，未获得可逐页核验的附件，不能将其记作已取得全文。

以上状态核对日期为 2026-10-26。发现新版不会使既有数学事实自动失效；可能受影响
的是要求范围、表述、选学与必学边界、学段安排及教材对齐，需要逐项处理。

## 一条条款如何进入新版

1. 取得可核验的新旧原文，登记来源网址、出版/发布机构、文件 SHA-256、印刷页及
   PDF 页。扫描件 OCR 只能辅助检索，引用需回看原页。
2. 保留旧条款 ID 与旧摘录哈希。为新版本建立独立记录和跨版本关系，不能直接
   改写旧正文而继续声称旧审核有效。
3. 按内容要求、学业要求、教学提示等位置逐条比对，记录 `unchanged`、`reworded`、
   `scope_changed`、`added`、`removed` 等差异分类和新页码。全文尚未取得时保持
   `pending_source`；已有原文但未比对时为 `pending_comparison`。
4. 对照新要求逐项列出受影响的教材导航、学习目标、讲解条件、任务和评价量规。
   一个细目标不能代表整个章节，课标条款存在也不证明项目已提供可教学内容。
5. 由教师或学科专家审核，登记审核者、记录 ID、涉及版本、原文定位及结论。
   AI 比对结果只能进入 `pending_review`。真实独立审核完成后才记 `reviewed`。
6. 更新内容后重新生成哈希、执行数据来源重建和结构检查，再执行受影响的判分、
   教学任务与迁移回归；旧版本学习记录仍绑定原题快照，不能用新版答案重判旧提交。

当前 78 个差异工作项都处于待取得原文状态。这是已有条款的工作清单，不是全部
课标条款的完整分母。获取新版全文后，还要逐页登记此前没有建模的新增要求。

## 覆盖报告的六个分母

运行：

```bash
python tools/check_projects.py
python tools/coverage_report.py --check
python tools/coverage_report.py --json --output build/coverage_report.json
```

| 层面 | 分母与含义 | 不能据此推断 |
| --- | --- | --- |
| 教材导航 | `topics.json` 的节点数 | 章节内所有细技能均已覆盖 |
| 讲解材料 | 全部导航节点，及其中 core 节点 | 速查卡等于完整教学；一张卡涵盖全部课标 |
| 细技能任务 | 实际编写的单元目标与各阶段任务 | 当前单元数除以章节数就是课程覆盖率 |
| 综合实践 | 原目录中 activities/projects 的具体题名 | 有活动标题就有课堂材料，或项目完成就掌握 |
| 独立教师审核 | 单元、项目各自的资源总数；批准必须绑定哈希 | 程序校验、作者自审或 AI 复核等于教师审核 |
| 学生证据 | 经审核的真实试点参与者与可比任务 | 匿名日志、演示会话和模拟答题就是教学成效 |

完整卡缺口与应用任务缺口分开登记。教材节点关联了一个新单元，也只说明该单元中
列明的目标有材料；尚不能从完整卡待办中自动删除整个节点。全课程细技能总数未完成
拆解，报告的该分母与覆盖率使用 `null`，不用看似精确的百分比掩盖未知。

## 综合实践的当前边界

新增三个原创材料包使用原目录题名作为导航：五上“有趣的密铺”、六上“水是生命之源”、
七上“进位制的认识与探究”。包含可操作步骤、学生交付物、条件、反例和人工评价量规；
没有复制教材正文。学生界面公开任务与量规标准，教师示例答案保留在源文件。

“水是生命之源”的备用数据明确标为模拟课堂算例。只有实际测量才可记为实测资料；
即使实际测量，也不能自动当成经过研究设计与审核的教育效果证据。三个材料包目前均为
AI 作者初稿，教师审核待完成。其余目录活动在覆盖报告中逐项保持 `pending_development`。
