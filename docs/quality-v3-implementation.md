# Quality V3 实施台账

本轮从 `a7988876eeb61ebfd5841c4f883170289d11c25e` 开始，使用分支 `codex/cnkg-quality-v3`。目标是修复上一轮门禁未覆盖的实际问题，补充统计学习链，并把失败恢复与键盘操作纳入正式发布验收。教师独立审核与真实学生教学效果验证继续按用户要求暂缓。

## 本轮复查确认的问题

| 范围 | 可复现的问题 | 修复的验收要求 |
| --- | --- | --- |
| 页面恢复 | `?target=` 页面刷新会再次创建会话，继续消耗未呈现题 | URL 指向已创建的会话；刷新与后退恢复同一位置 |
| 失败草稿 | 保存失败后切换页面，编辑器可能被移除，未保存文字不可访问 | 导航前处理待保存内容；失败与冲突保留可见草稿和恢复入口 |
| 编辑器加载 | 读取作品失败后，外部输入框仍可编辑，但没有保存监听 | 加载失败时不显示为可正常保存，允许重试 |
| 复测间隔 | 手工传入较早记录可以忽略同范围较新的完成记录 | 按同一范围最近实际记录计算间隔，不能凭旧链接抬高间隔 |
| 复习阶梯 | 即时重复复测也累加 1／3／7 天次数 | 只有满足实际间隔的记录推进默认复习阶梯 |
| 过程自查 | 一条备注或部分自评就可能消除整道题的待自查提示 | 逐项检查当前量规；未检查项继续显示 |
| 历史规模 | 计划仅传入前 1,000 份作品，较早草稿与自查记录会消失 | 汇总读取覆盖该所有者的全部相关作品 |
| 可读导出 | 仅有 `o1/o2` 等选项 ID 的作答，离开当前库无法还原题义 | 导出已呈现内容的冻结题面、选项和图示，维持未公开反馈的隔离 |
| 内容条件 | 百分位数、分层抽样、相关／回归解释及几何候选存在条件遗漏 | 在原作者源逐题修订并保留 ID；以数学反例检查 |
| 统计深度 | 已有统计教材卡和项目，缺少分阶段的统计学习单元 | 增加有具体目标、图示、例题、过程量规和迁移任务的三学段单元 |
| 键盘和辅助技术 | 选择状态仅靠 CSS，视图切换没有焦点提示 | 提供可识别的单选语义、键盘选择、明确焦点与状态通知 |

## 三批实施范围

### 第一批：连续学习与记录可靠性

后端提交：`f10ed1e`。修复复习间隔、自查汇总、作品计划截断与导出；页面恢复和失败草稿保护在第三批界面整合中完成。保持现有评分程序及答案契约，原始作答和历史修订不重判、不删除。

服务端使用最新同范围完成记录及相关内容提供事件；旧链接不能把最近活动排除在外。重新打开旧答案、过程作品、冻结图示或导出记录也会追加实际提供内容的事件，不改写原会话。复测上下文分别记录距完成与距最近活动的时间，并给出具体提示；立即重复不推进1／3／7天的默认安排。

学习数据库v3只重建派生摘要和复习索引。85项针对性存储、计划与HTTP检查全部通过，包含实际DDL失败回滚、原记录JSON逐字节保留、1,001份作品、跨所有者隔离、已呈现内容导出及重复查看计时。新增23项回归；这些测试没有读取或修改真实学生记录。

### 第二批：统计学习链与内容修订

内容提交：`152e5d7`。

在原作者JSON中修正13道题的具体数学表述，同步11条由题面和解释派生的核验字段，保留原ID、答案及原有练习／诊断用途。两道空间题还核对了修改解释产生的自动分级变化：初中题的说明更完整，但仍明确保留仅练习的原有用途，不自动升级为诊断证据。修正及前后指纹见 `data/migrations/quality-v3-corrections.json`。

补充小学读图与平均数、初中抽样与波动、高中相关与回归三个单元：新增15个可观察目标、45道任务、12个例题及4幅SVG。包含26道可自动判分题和19道过程量规题；每个新目标在练习、迁移和后续复测中都有具体任务。15项内容回归检查真实数学反例、精确答案与条件边界，详细说明见 [统计内容说明](quality-v3-content.md)。

新技能中11项通过14条关系细化旧目标，13条先修关系逐项核对；另4项缺少准确旧目标对应而保持未映射。关系依据位于 `data/migrations/quality-v3-skill-links.json`。全项目现有1,112项技能登记、4,546项任务和509项材料；14个单元共有104个目标、222道任务和56个例题。旧954个教材复合目标与84个其他复合目标保留身份，只有74项标记为可观察目标。

与基线对照，原4,501个任务、1,097个技能的身份、全部有效答案契约及原有准入用途保持；原11个单元的内容版本及评分／推断程序字节没有变化。唯一的旧题派生策略字段变化是初中空间题的说明由bare变为explained，其诊断资格仍保持关闭。编译、迁移和当前测试不代表穷尽课程语义或实测题目难度。

### 第三批：操作可达性与交付

把导航恢复与键盘操作的实际界面流程加入正式浏览器门禁，保留原有六条流程。发布仍要求同一干净提交、完整核心检查、全部浏览器流程、字节清单以及实际恢复通过的 Git bundle。

界面使用具体会话／作品地址恢复位置，切换前处理待保存草稿。恢复失败时禁用输入并提供重试；修订冲突保留服务器已有记录及可见的未保存草稿，选择保留两版且保存成功后才追加历史修订。选择题改为原生单选组，提供焦点提示、状态通知和跳到正文的入口；图示可以在新标签页查看大图，原页及草稿保留。

新增 `navigation_recovery` 和 `keyboard_accessibility` 两条真实界面流程，检查断网、409冲突、加载失败、刷新与前进／后退、键盘单选和焦点。开发验证还发现自动保存期间禁用按钮可能吞掉“提交我的自查”的点击，已将保存请求串行处理并保留提交意图，增加受控延迟回归。手机流程检查新统计链、实际SVG与大图查看。

八条开发浏览器流程已运行；其中过程自查在修复自动保存竞态后复验通过，手机流程也复验了实际大图入口。正式验收数据在构建和提交后生成，见 `build/regression_report.json`、`build/browser-check/report.json` 以及对应发行目录的 `delivery.json`。未提交的开发检查不替代正式发行证据。

## 证据边界

浏览器流程使用独立临时数据库及合成作答。键盘、焦点、单选和状态消息的定向检查不构成完整无障碍符合性认证；可对照 [W3C 单选组模式](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) 与 [状态消息说明](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) 理解本轮范围。

复习 1／3／7 天仍是可解释的产品默认规则，没有被当作经真实学生验证的最佳间隔。自评是学习者报告，任务族是作者声明，不能被转换为独立掌握证据。
