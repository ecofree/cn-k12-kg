# 给 Astra 的任务包

这五份 CSV 是用来补项目里**我拿不到的外部信息**。填好后放回 `inbox/` 目录（或整包回传），我会跑 `python tools/ingest.py --check` 校验，通过后再 `--apply` 写回。

## 三条硬规则

1. **`id` 是唯一连接键，一个字符都不能改。** 知识点重名很常见（「平均数」在小学 `m5b.6.1` 和初中 `m4b.6.1` 各有一个），靠名字回填必错。
2. **宁可留空，也不要猜。** 空着我会当作「未提供」；填错会被当成事实，比空着危险得多。
3. **不要增删列、不要改列名。** 需要补充说明就写在 `note` 列里。

优先级：`kc_map.csv`（价值最高）→ `review.csv` → `standards.csv` → `outline.csv` → `question_stats.csv`。

## 2. `kc_map.csv` — 外部知识点体系映射（最高优先）

**解决什么问题**：项目里 568 条先修边的强弱（hard/soft）和 1077 道题的难度，全是我主观标的。要改成有依据的，必须先有一个外部体系的知识点映射，然后用它的真实答题数据算。

**填什么**：把 XES3G5M 的 865 个 KC 逐个对到 `topics.csv` 里的 `id` 上。

| 列 | 含义 | 必填 |
|---|---|---|
| `kc_id` | 外部体系的原始 id | 是 |
| `kc_name` | 外部体系的原始名称 | 是 |
| `topic_id` | 对应的我方 id，**必须存在于 topics.csv** | 是 |
| `confidence` | `high` / `medium` / `low` | 建议填 |
| `note` | 判断依据，如「同名且同年级」 | 建议填 |

示例：

```csv
kc_id,kc_name,topic_id,confidence,note
100001,有理数的概念,m7a.1.2.1,high,同名且都在七上第一章
100002,有理数的加法,m7a.1.3.1,high,
100003,数的分类,m7a.1.2.1,medium,概念覆盖但不完全对应
```

**允许的情况**：

- 多个 KC 对到同一个 topic（粒度不同），照填即可
- 一个 KC 对不上任何 topic，留空并在 `note` 写「无对应」
- 我方一个 topic 没被任何 KC 覆盖，不用管

**验收标准**：覆盖率 ≥ 90%；我抽检 100 条，一致率 ≥ 90%。

**不要做**：不要为了凑覆盖率硬对。对不上的留空，比错配有用。

## 3. `review.csv` — 题目复核（次高优先）

**解决什么问题**：1077 道题全部 AI 生成、零教师审核。`review.csv` 里是我按风险挑出的 160 道（所有短答 + 所有 standard + 每册 3 题）。

**两种填法**：

- 直接编辑 `review.csv`；
- 或者打开 `http://127.0.0.1:8765/static/review.html`，用快捷键 `1` 通过 / `2` 有问题 / `3` 跳过，点「导出 review.csv」，导出的文件与模板同格式。

**填什么**：逐题判断，在 `verdict` 列填一个值。

| verdict | 含义 |
|---|---|
| `pass` | 题干、答案、解析都正确 |
| `fail` | 有问题，必须在 `note` 写清哪里错、应该改成什么 |
| `skip` | 无法判断（超纲、表述歧义、缺图），`note` 写原因 |

**重点看什么**：

- **单选正确项**是否真的唯一正确，有没有两个选项都对
- **解析**有没有讲错，或者和答案矛盾
- **短答题**的标准答案是否唯一，`accept` 里的同义写法够不够（学生写「a平行于b」会被判错，这类要补进 `accept`）
- **数值题**虽然过了表达式验算，但题干里的情境可能不成立（如「每人分 3.5 个苹果」）

**验收标准**：`fail` 的题逐条给出修正建议；抽样一致率 ≥ 95%。

**边界说明**：如果 Astra 是 AI，这属于「独立第二遍复核」，能发现问题，但和我是同类错误源，**不能替代教师审核**。请在回传时说明复核主体是人还是模型，我会在数据里分别标注 `ai-reviewed` / `teacher-reviewed`，不会混为一谈。

## 4. `standards.csv` — 课标原文核对

**解决什么问题**：`data/standards.json` 里 78 条课标全是我按记忆写的概述，`verbatim: false`、`page_or_ref: "待核"`。项目对外说「映射课标」，但引用的不是原文——这是事实性风险。

**填什么**：只填两列。

| 列 | 填什么 |
|---|---|
| `verbatim_text` | 课标原文（逐字，不要改写、不要省略） |
| `page_or_ref` | 出处，格式 `2022版 第三学段 内容要求 第22页` |

`current_summary` 是我写的概述，供你对照定位，**不要改它**。

`verbatim` 列：能确认逐字一致的填 `true`；只能确认意思一致但找不到原文的留空（我会保持 `false`）。

**找不到的条目**：`verbatim_text` 留空即可，不要用相似条款替代。

**验收标准**：能核对到原文的条目 ≥ 70%；每条都有页码或条款号。

## 5. `outline.csv` — 教材目录细化

**解决什么问题**：人教版 2024 版小学教材，有 3 册我只有单元名、4 册只有节名，拆不到课时。其中四下、五下、六下各只有一个知识点覆盖整章，诊断定位不到具体内容。

**填什么**：7 册（四下、五下、六下、二下、四上、五上、六上），按现有行修改，或新增行。

| 列 | 说明 |
|---|---|
| `volume` | 册次，不能改 |
| `chapter_no` / `chapter_title` | 章号与章名 |
| `leaf_no` | 叶子编号，如 `3.2`；新增时必填 |
| `leaf_title` | 叶子名称；新增时必填 |
| `action` | `keep` 保留原样 / `new` 新增 / `rename` 改名 / `drop` 删除 |
| `source` | **新增或改名必须填**：哪本书、哪一页、哪个网站 |

**要特别小心的事**：网上大量「2024 版四下新教材目录」实际是 2012 版内容（四则运算 / 观察物体（二） / 运算定律），而教育部审定 2024 版是「除数是两位数的除法 / 混合运算和运算律 / 三角形 / 小数的认识…」。**判断依据是章名，不是标题里有没有写「新教材」**。拿不准就留 `keep`，并在 `source` 写「待核」。

**验收标准**：新增叶子能与纸质教材或官方 PDF 逐条对应；`source` 可追溯。

## 6. `question_stats.csv` — 真实作答正确率（可选，最后做）

**解决什么问题**：题目难度全是主观标的（1042 道 basic、35 道 standard）。有了真实正确率才能回填。

**前提**：必须先完成 `kc_map.csv` 并通过抽检，否则题目对不上，统计没有意义。

| 列 | 说明 |
|---|---|
| `question_id` | 我方题目 id |
| `attempts` | 作答次数（正整数） |
| `correct_rate` | 正确率，0—1 之间的小数 |

**注意**：只有 `attempts` 足够（建议 ≥ 30）的题才有统计意义，样本太小的行直接不填。

## 回传后我会做什么

```bash
python tools/ingest.py --check   # 校验：id 是否存在、字段是否合法、覆盖率
python tools/ingest.py --apply   # 写回：课标补原文、复核结论入库
```

- `standards.csv` → 写进 `standards.json`（保留我的摘要，新增原文与出处）
- `review.csv` → 汇总到 `data/reviews.json`，`fail` 的题我会逐条改
- `kc_map.csv` → 落到 `data/external/`，抽检通过后才用来回填难度
- `outline.csv` → 生成提案，人工确认后再合并
- `question_stats.csv` → 落到 `data/external/`，等映射确认后使用

**我不会自动做的事**：改题目难度、改先修边。这两件必须等映射抽检通过——否则就是把「看起来有条理」的数字当成校准结果。
